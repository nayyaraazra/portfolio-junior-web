# Proyek 1: Landing Page - Toko Roti Rasa Nusantara

Landing page responsif untuk usaha *bakery* fiktif **Toko Roti Rasa Nusantara**, proyek pertama Diklat Junior Web Programmer.

## Tema

**Profil UMKM**. Galeri produk, tabel jadwal produksi, dan form pemesanan sangat relevan dengan kebutuhan usaha kecil sehari-hari.

## Fitur

- Struktur HTML semantik: `header`, `nav`, `main`, `section`, `article`, `footer`
- Navbar Flexbox: menu menumpuk di ponsel, sejajar dan menempel (sticky) di tablet ke atas
- Kartu produk dan galeri 6 gambar dengan CSS Grid
- Tabel jadwal produksi (`thead`, `tbody`, `tfoot`) yang bisa digulir horizontal di layar kecil
- Form pemesanan dengan validasi HTML5 (`required`, `type="email"`, `type="tel"`, `pattern`)
- Responsif di 360, 768, dan 1280 px; warna dan jarak memakai variabel CSS
- Efek `:hover` pada tombol dan kartu, `:focus` pada input

## Teknologi

HTML5, CSS3 (Flexbox, Grid, variabel CSS, media query), GitHub Pages
