# Pengolah Nilai Siswa

Program Node.js sederhana untuk mengelola nilai siswa melalui menu interaktif.

## Fitur

1. Input data siswa
2. Menampilkan statistik nilai
3. Menampilkan grade dan status kelulusan
4. Keluar dari program

## Aturan Penilaian

### Kelulusan
- Lulus : nilai >= 70
- Tidak Lulus : nilai < 70

### Grade
- A : 85 - 100
- B : 70 - 84
- C : 55 - 69
- D : < 55

## Cara Menjalankan

Pastikan Node.js sudah terinstal.

```bash
node index.js
