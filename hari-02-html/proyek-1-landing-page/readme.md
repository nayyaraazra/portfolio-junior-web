# Proyek 1: Landing Page - Toko Roti Rasa Nusantara 🍞

Halo! Selamat datang di repositori proyek pertama untuk Diklat Junior Web Programmer.

## 📌 Tema Proyek

Dari tiga pilihan studi kasus yang ada, saya memilih tema **Profil UMKM**. Spesifiknya, saya membuat halaman pendaftaran dan profil untuk sebuah usaha *bakery* fiktif bernama **Toko Roti Rasa Nusantara**. Saya merasa tema ini cocok karena elemen seperti galeri produk, tabel jadwal, dan form pemesanan sangat relevan dengan kebutuhan bisnis UMKM sehari-hari.

## 📂 Daftar Halaman

Sesuai instruksi dari modul (minimal 1 halaman utama dan 1 halaman tambahan), proyek ini terdiri dari dua berkas HTML:

1. `index.html` - Halaman *landing page* utama (berisi bagian hero, tentang kami, produk, galeri, jadwal, dan kontak).

2. `katalog-lengkap.html` - Halaman ekstra yang dihubungkan melalui navigasi dari halaman utama.

## ⚙️ Fitur dan Struktur HTML

Dalam menyusun kode HTML ini, saya sudah menerapkan:

* **Elemen Semantik**: Menggunakan `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, dan `<footer>` agar struktur lebih rapi dan ramah SEO/aksesibilitas.

* **Tabel**: Terdapat tabel jadwal produksi lengkap dengan `thead`, `tbody`, dan `tfoot`.

* **Formulir**: Form pemesanan dengan atribut validasi bawaan HTML5 (seperti `required`, `type="email"`, `type="tel"`, `minlength`, dll).

* **Galeri**: Area galeri yang menampilkan 6 gambar produk.
